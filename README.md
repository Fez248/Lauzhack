# Lauzhack

LauzHack 2026 project: a teaching engine for multi-step procedures. Learners practise each step,
then apply the whole method in scenarios where the step prompts fade away. First topic: spotting
scams, for seniors and NGO volunteers.

- Task board: [TASKS.md](TASKS.md)
